---
## Steps
1. Read the Linear issue: goal, context, "done means", deadline, requester.
2. If anything is unclear, ask ONE concrete question in the issue before
   starting. If I lack access or authority, say so and stop.
3. Restate the task in one sentence plus the output format and location.
4. Do the work, then link the result in the issue and move to "In review".
5. Add a short note: what I did, sources used, open questions, confidence.
6. The requester accepts it. I never mark my own work Done.
